📈 Stock Market Dashboard

A simple Stock Market Dashboard built using HTML, Bootstrap, JavaScript, Google Charts, and the Alpha Vantage API. This project fetches real-time intraday stock market data and displays key statistics along with an interactive line chart.

🚀 Features

📊 Fetch real-time stock market data
📅 Display the latest trading date
📈 Show the maximum stock price
📉 Show the minimum stock price
📊 Visualize trading volume using Google Charts
🌙 Dark theme interface with Bootstrap 5
⚡ Fast and lightweight
🛠️ Technologies Used

HTML5
Bootstrap 5
JavaScript (ES6)
Google Charts
Alpha Vantage API

⚙️ How It Works

Click the Fetch Data button.

The application sends a request to the Alpha Vantage API.

It retrieves the latest intraday stock data.

The dashboard displays:

Latest trading date
Highest stock price
Lowest stock price
Trading volume graph
▶️ Running the Project

Clone the repository:
bash git clone https://github.com/your-username/stock-market-dashboard.git

Open the project folder.

Open index.html in your web browser.

No installation is required.

🔑 API Information

This project uses the Alpha Vantage API.

The demo API key is included for testing purposes:

javascript apikey=demo

For your own projects, create a free API key from:

https://www.alphavantage.co/support/#api-key

Replace the demo key in stock.js with your personal API key.
